### Git Commands for Project

```bash
# Start new feature
git checkout develop
git pull
git checkout -b feature/phase-1-task-name

# Daily workflow
git add .
git commit -m "feat(phase-1): description"
git push origin feature/phase-1-task-name

# Create PR
# → Go to GitHub and create PR to develop

# After PR merged
git checkout develop
git pull
git branch -d feature/phase-1-task-name
```
